The Pi Academy Setup

Download the coding camp projects, install useful editors, and prepare standard dependencies from one terminal interface.

Install

Run this on Raspberry Pi OS 64-bit for Raspberry Pi 4 or newer:

sudo apt-get update
sudo apt-get install -y curl
curl -fsSL https://the-pi-academy.github.io/tpa_tui/install.sh | bash
Repositories

Projects are cloned into ~/thepiacademy. The setup tool itself lives in ~/thepiacademy/tpa_tui.

Editors

Installs VS Code where available, plus Thonny, Geany, Mousepad, and Nano for simpler editing paths.

Dependencies

Uses apt, Python virtual environments, Maven, and project-specific setup commands based on each standard repository.

Optional ML

The object detection demo is left out by default. Add it later from the TUI or with --include-optional --include-heavy.
